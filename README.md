# 群星之间

一个面向游戏、影视与动漫虚构宇宙的观测与调查系统。访问者从星图选择世界，再通过档案、关联与时域等观测镜探索同一组世界记录；每个 IP 可以拥有自己的页面语言、动效和交互，但不能产生一份彼此矛盾的数据副本。

[访问 GitHub Pages](https://atsmoe.github.io/.ats/)

## 当前内容

- 明日方舟：泰拉总入口、独立主编年与七个集成战略专题
- 战锤 40K：银河总入口、规范编年、九大阵营与六大战区
- 最终幻想 XIV：水晶星海入口、规范编年、十四镜界与八段旅途
- 星图入口：连接各世界及跨世界引用

三个世界共享 `WorldArchive` 的规范记录与稳定 ID，但分别使用泰拉战术网络、帝国银河档案和水晶以太星海作为探索语言；Lens 只改变阅读方式，不复制事实正文。

## 核心约束

- 一个世界只有一组规范记录；档案、关联和时域只是不同投影。
- 世界内部的数据语义保持统一，世界外部通过稳定 ID 引用，避免后续出现分叉副本。
- 全站导航与可访问性规则保持稳定；视觉与动效由各 IP 的 Adapter 单独实现。
- 内容采用原创摘要并保留可追溯来源；无法核验的材料不作为正式事实发布，不使用含混的“二手整理”标签。
- PC 是完整体验目标，手机保证正常顺序阅读，不为低端设备单独裁剪内容。

详细设计见 [世界档案架构](docs/WORLD_ARCHIVE.md)。

## 本地开发

```bash
npm install
npm run dev
```

生产构建与测试：

```bash
npm run build
```

构建产物输出到 `dist/`，由 GitHub Pages 发布。
