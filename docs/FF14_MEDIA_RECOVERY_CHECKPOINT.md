# FFXIV 编年媒体来源重建：长期目标检查点

保存时间：2026-08-25 20:23:29 +08:00

## 长期目标

以低流量、零人工复核方式重建 FFXIV 编年图片与文字的来源关系。缩略图只用于匹配证据；生产页面只展示哈希和尺寸均与公开来源原图一致的本地副本。不可信、冲突或无法证明的映射自动隐藏。

硬约束：

- 不上传本地素材。
- 不下载大型模型；原图仅限已高置信映射的精确公开 URL，并执行逐项限流和完整性核验。
- 联网阶段默认只读取 Wiki 文本、图片元数据和小缩略图；原图补齐独立限为单项 8 MiB、批次 32 MiB、无重定向、identity 编码、15 秒超时、必须 Content-Length。
- 保留共享工作树中的所有无关改动，不做 reset、checkout 或机械化全量暂存。
