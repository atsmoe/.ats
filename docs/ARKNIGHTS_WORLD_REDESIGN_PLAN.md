## 一、结论摘要

本次将当前 `arknights.html` 从水月首屏改为泰拉总入口，并重新划分页面职责：

1. `arknights.html` 成为“泰拉世界总入口”，不由任何单一活动或角色代表整个世界。
2. 主世界线迁入独立编年页面，重型虚拟时间轴不再与世界首页共用滚动坐标。
3. “集成战略世界线”拥有独立索引，并从第一版起收录全部七个主题。
4. 当前“深蓝观测记录”的结构与视觉资产迁移到“水月与深蓝之树”专题页，不再作为明日方舟首页。
5. 七个专题共享数据语义、导航、剧透、来源与 URL 规则，但各自拥有主题皮肤和叙事拓扑。
6. 网站只做剧情世界线档案，不复制 PRTS 的完整攻略、关卡与收藏品百科。
7. 不再展示“二手整理”标签。无可追溯来源的内容不作为正式事实发布。

## 四、泰拉世界首页

### 首页任务

首页只做三件事：

1. 建立“这是泰拉世界入口”的第一印象。
2. 让用户理解有哪些探索方向。
3. 把用户送到正确的独立内容页。

### 首屏构成

- 泰拉观测状态与世界名称。
- 抽象的泰拉信号图或战术网络，不使用某个活动的单张宣传图充当首页。
- 四个一级入口，支持鼠标探索和键盘直接访问。
- “最新观测”展示当前仍在更新的“沉沦者的黑流树海”，但它只是动态推荐，不改变首页结构。
- 数据更新时间、覆盖范围与 PRTS 鸣谢放在次级信息区，不抢占主叙事。

### 交互原则

- 探索感来自信息逐步显现、信号响应、路径反馈和空间层次，不来自隐藏正文或制造不可点击入口。
- 所有看起来可点击的元素必须真正可点击。
- 特效不能承担唯一导航功能；关闭动画后仍能完成全部操作。
- 首页不加载 875 条主线事件和虚拟时间轴逻辑。

## 五、集成战略世界线索引

### 索引定位

索引只承担七个主题的总目录职责，水月与其余六项均进入各自专题。

七个主题按发布顺序展示为 `IS-01` 至 `IS-07`。连接关系只表示产品主题顺序，不暗示七个故事处在同一条正史时间线上。

### 每个索引项展示

- 正式名称与序号。
- 一句话主题命题。
- 代表性视觉信号。
- 已收录结局数量。
- 资料最后核验时间。
- 进入专题的真实链接。

索引不使用“待完工”死卡片。内容仍在更新时，页面可以明确显示最近核验日期，但入口必须可用。

## 六、七个专题的共同内容契约

每个专题至少包含以下六个部分：

1. **主题概览**：背景、探索者身份、故事命题。
2. **共同起点**：各个结局共享的前提，不提前制造分歧。
3. **叙事拓扑**：条件、转折和结局之间的真实关系。
4. **结局记录**：标题、条件、原创摘要、后续与具体来源。
5. **关联记录**：关键人物、组织、地点与概念；只显示有目标的链接。
6. **来源与核验**：页面级来源、逐条来源、资料更新时间。

关卡、收藏品、天赋树、商店与玩法机制只在解释剧情条件时引用，不建设完整攻略表。

### 叙事拓扑规则

- 明确存在路线依赖时，可以画分支路径。
- 并列可能性使用互斥档案或观测记录。
- 循环、历史重构、多层叙事允许使用环形、层叠或递归结构。
- 来源未说明先后关系时，不为视觉效果虚构连接线。
- 视觉拓扑只是规范记录的投影，不拥有第二份事件数据。

## 七、统一骨架与七种主题皮肤

专题共同使用相同的页面结构、DOM 语义与交互 API。皮肤只通过主题配置改变颜色、纹理、构图、动效和局部组件形态。

| 主题 | 视觉与交互方向 |
| --- | --- |
| 刻俄柏的灰蕈迷境 | 孢子、热雾、梦境残片与不稳定记忆 |
| 傀影与猩红孤钻 | 猩红舞台、幕布、聚光灯与剧目线索 |
| 水月与深蓝之树 | 深海观测、生物荧光、潮汐与多结果记录；迁移当前页面资产 |
| 探索者的银凇止境 | 极地测绘、等高线、远征信号与坍缩干扰 |
| 萨卡兹的无终奇语 | 历史残片、语言记录、覆写痕迹与多层叙事 |
| 岁的界园志异 | 界园、墨迹、印章、折叠边界与卷轴空间 |
| 沉沦者的黑流树海 | 黑流数据库、生命演化、树状增殖与分形递归 |

视觉素材来源与形式不设限制，以主题契合、主流审美和最终页面质量为选择标准。可综合使用官方宣传图、游戏截图、社区公开素材、原创 CSS / Canvas / SVG 与生成素材；外部资源应转为站点可稳定部署的本地资产并记录来源，避免热链失效。

### 主题配置边界

主题配置可以决定：

- 色彩、纹理和字体组合。
- 背景粒子或 Canvas 预设。
- 叙事拓扑渲染器。
- 入场、聚焦和切换动效。
- 局部术语与装饰标签。

主题配置不能决定：

- 记录正文和结局事实。
- 稳定 ID。
- URL 规则。
- 来源、剧透、键盘和移动阅读规则。
- 全站导航与错误恢复。

## 八、数据模型

### 内容数据与视觉配置分离

- `src/_data/arknights.json`：主题背景、记录、结局、实体关系、来源和核验日期。
- `WorldArchive`：编译上下文、稳定记录和引用关系。
- 集成战略索引：只引用七个上下文 ID。
- 主题视觉配置模块：只保存皮肤 token 和拓扑渲染器名称，不保存剧情正文。
- 专题页：消费 `WorldArchive` 快照，不直接遍历原始嵌套 JSON。

### 来源规则

- 每个主题至少有一个有效的官方或 PRTS 页面级来源。
- 每个正式结局记录必须有稳定 ID 和可追溯来源。
- 页面显示“资料来源”和“最后核验”，不显示“二手整理”。
- 暂时无法核验的摘要保留在内容工作清单，不进入公开数据。
- 构建校验拒绝重复 ID、悬空引用、空来源的正式结局和“待完工”占位文本。

## 九、当前已知布局缺陷及设计级修复

### 1. 顶部重复留白

导航高度只能由页面外壳预留一次。专题组件、首页组件和时间轴组件不得再次添加 `var(--nav-h)` 外边距。

验收：滚动到页面顶部时，固定导航底部与首个页面区域之间不存在额外 56px 空洞。

### 2. 虚拟时间轴坐标错位

虚拟条目的 `item.top` 是容器局部坐标，不能直接与 `window.scrollY` 比较。所有可见范围、年代导航、深链接和高亮计算必须共享同一个坐标转换函数：

```text
containerDocumentTop = container.getBoundingClientRect().top + window.scrollY
localScrollTop = window.scrollY - containerDocumentTop
documentTargetTop = containerDocumentTop + item.top
```

主世界线迁入独立页面后仍需修复该函数，不能依赖“容器碰巧靠近页面顶部”。

### 3. 小窗口卡片越界

布局断点按内容容器可用宽度设计，舍弃 `27vw` 与固定卡宽的组合。

- 宽桌面：双列时间轴。
- 窄桌面和平板：紧凑单列或安全的不对称布局。
- 手机：完整线性阅读。
- 任何断点下，事件卡的左右边界都不能超出内容容器。

重点测试宽度：1920、1440、1280、1024、900、768、390px。

### 4. 吸顶栏遮挡

固定导航、主题切换栏和内容锚点使用统一的 sticky offset token。锚点设置 `scroll-margin-top`，内容不能落在吸顶栏下面。

### 5. 假入口

移除不可点击的“02 关联 / CALIBRATING”。首版只渲染已有内容和真实链接；未实现功能不进入导航。

## 十二、验收标准

### 世界首页

- 首屏不会让用户误以为“明日方舟 = 水月肉鸽”。
- 四个一级入口都是真实链接。
- 最新主题可以突出，但不能替代世界结构。
- 首页不加载主世界线的巨量 DOM 或虚拟滚动逻辑。

### 集成战略

- 七个主题全部可进入，没有“待完工”死卡。
- 每个专题都能直接分享和刷新恢复。
- 水月旧页面内容出现在正确的新位置。
- 黑流树海包含当前三个正式结局及来源。
- 七个页面骨架一致，主题表现明显不同。
- 页面不伪造七个主题之间的正史时间关系。

### 布局与交互

- 页面顶部无重复导航空隙。
- 900px 宽度不再截断左侧事件卡。
- 点击“时域”后首屏能看到真实内容，不出现虚拟渲染假空白。
- 锚点内容不会被固定导航或吸顶栏遮住。
- 页面不存在看起来可点击但无法操作的控件。
- 手机无需横向拖动即可阅读全部正文。

### 数据与来源

- 七个上下文 ID 唯一且稳定。
- 专题、编年和关联视图引用同一批规范记录。
- 正式结局均有来源，不显示“二手整理”。
- 构建能检测悬空引用、重复 ID 和占位内容。

## 十三、非目标

本轮不做：

- 完整复制 PRTS 的关卡、收藏品、天赋树与攻略数据。
- 全泰拉实体关系可视化网络。
- 用户账号、收藏、进度同步或后端数据库。
- 低端手机专门特效优化。
- 音效系统。
- 未经复核的 AI 推测内容。
- 未经用户确认的自动推送与部署。

## 十四、主要风险与约束

1. **内容量风险**：七个主题全部上线意味着先满足统一最低契约，再逐步扩充，不能用一个主题的完成度绑架全局上线。
2. **最新资料变化**：黑流树海仍在更新，必须保存 `lastReviewedAt` 并允许追加记录。
3. **主题皮肤失控**：视觉发散必须停留在 Adapter；事实结构和核心操作不能分叉。
4. **虚拟滚动回归**：页面拆分不能替代坐标修复，必须有 900px 与锚点回归测试。
5. **来源不完整**：宁可暂不发布某条摘要，也不恢复含糊的“二手整理”兜底。
